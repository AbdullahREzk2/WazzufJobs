# Release P01: .NET 9 → .NET 10 (LTS) runtime upgrade

Status: **DEPLOYED to production and verified on 2026-10-31.** Production runs .NET 10.0.14 (X86). Phase 01 is closed; pushing and merging still need owner approval.
Branch `upgrade/net10` (from `master` `ea5e542`); code commit `effff4b`.
Reason: .NET 9 reaches end of support on 2026-11-10; .NET 10 is LTS (supported to 2028-11).

### Remaining items (non-blocking)
- **No Phase 01 blockers are open.** No security, schema or compatibility issues remain.
- **Rollback window:** the rollback below works only while the .NET 9 x86 runtime is on MonsterASP and supported (until 2026-11-10). After that, the recovery path is maintenance mode (`app_offline.htm`) plus a fix forward on .NET 10.
- **Obsolete server files:** `System.Runtime.Caching.dll`, `System.Security.Permissions.dll` and `System.Windows.Extensions.dll` remain on the server, unused. Their cleanup is part of the separately approved obsolete-file cleanup.
- **Unchanged items:**
  - CV uploads (D21b), Google sign-in, admin e-mail change and the DB reset still need separate approval;
  - unused third-party packages (Anthropic, Mscc, PdfiumViewer, Tesseract, duplicate PdfPig) remain; removal is planned for a later phase.
- **Local environment only:**
  - the untracked Visual Studio publish profile still targets `net9.0`; it is not used;
  - local user secrets lack `MailSettings:Username`/`FromEmail`, which the API requires at startup.
